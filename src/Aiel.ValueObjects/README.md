# Aiel.ValueObjects

Provides a set of value objects for use in .NET applications. Value objects are immutable types that represent a concept or value in your domain model, such as money, date ranges, or email addresses. This library aims to simplify the creation and management of value objects, ensuring they adhere to best practices and provide a consistent API for developers.

## General

- `Address`
- `Country`
- `Currency`
- `Email`
- `EmailAddress`
- `PhoneNumber`
- `PostalCode`
- `Province`
- `State`
- `ZipCode`

## Networking and Internet

- `DomainName`
- `EndPoint`
- `Label`
- `Serial`
- `TTL`
- `Port`
